# 🎨 Disney-Pixar 3D Cartoon Moral Stories Shorts Generator

100% Free & Autonomous AI pipeline that generates heartwarming 3D Pixar-style moral stories in Hindi & Roman English/Urdu, complete with 4-shot cinematic animations, fairytale orchestral music, voice-synchronized animated typography, and auto-posts 3 times daily to Instagram Reels and YouTube Shorts via GitHub Actions.

---

## 🌟 Features

- **Disney-Pixar 3D Aesthetic:** High-resolution 1080x1920 3D characters rendered in charming storybook lighting with 3D camera pan, zoom, and crossfade transitions.
- **Heartwarming Moral Stories:** Timeless life wisdom stories (Aesop, Panchatantra, and modern fables) that inspire viewers of all ages.
- **Voice-Synchronized Animation:** Real-time word-level synchronization (`WordBoundary` events) powering elastic pop-in subtitle animations.
- **Fairytale Orchestral Soundtrack:** Gentle whimsical background music balanced perfectly underneath expressive neural storytelling narration.
- **Dual Subtitles:** Bold Hindi cartoon font on line 1, vibrant golden Roman English/Urdu on line 2.
- **Autonomous Publishing:** Posts 3 times daily to Instagram Reels & YouTube Shorts with zero server costs.

## 🔑 Required GitHub Secrets

Configure under **Repo -> Settings -> Secrets and variables -> Actions**:

- `INSTAGRAM_SESSION_ID`: Your browser `sessionid` cookie from instagram.com.
- `INSTAGRAM_USERNAME` & `INSTAGRAM_PASSWORD`: (Fallback credentials).
- `YOUTUBE_TOKEN_JSON`: (Optional) YouTube Shorts OAuth2 token JSON.
